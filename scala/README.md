# Apache Fory Scala

Apache Fory publishes two Scala artifacts for Scala 2.13 and Scala 3:

| Artifact                           | Purpose                                   |
| ---------------------------------- | ----------------------------------------- |
| `org.apache.fory::fory-scala`      | Fory binary serialization for Scala types |
| `org.apache.fory::fory-json-scala` | Fory JSON support for Scala types         |

The modules support the ordinary JVM and GraalVM Native Image. Android is not supported.

- [Binary Scala module](fory-scala/README.md)
- [Scala JSON module](fory-json-scala/README.md)
- [Scala JSON guide](../docs/json/scala.md)
